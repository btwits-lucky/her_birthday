# A Day Made Yours ♡ — For Quinter

A click-through birthday surprise made with plain HTML, CSS, and JavaScript. It is designed for GitHub Pages and works without a backend.

## Preview
Open `index.html` in a browser. The secret code is `03.08.15.12.05` (enter the digits `0308151205`).

## Files
- `index.html` — all screens and birthday content
- `style.css` — the original editorial cream, sage, slate, rust, and gold design
- `script.js` — keypad, screen navigation, flower transition, love note, and birthday wish
- `photos/favourite.png` — Quinter's original photo, unchanged

## Publish with GitHub Pages
Upload all files and the `photos` folder to the root of your repository. In repository Settings → Pages, choose deployment from the `main` branch and `/ (root)`. Keep the folder structure intact.

The website does not send data to a server, collect analytics, or require external libraries. The only photo section is `My Fav Photo`; the three encouragement cards are text-only.
